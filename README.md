# FitTrack

A responsive React fitness planner with a dashboard, workout planner, progress tracking, BMI and calorie calculators, and registration/login.

## Run locally

1. Install Node.js 18 or newer.
2. Run `npm install` from this folder.
3. Run `npm run dev` and open the local URL printed in the terminal.
4. Run `npm run build` to create the production build.

No backend is required. Register an account before signing in. Accounts and workouts are stored in this browser using local storage. The workout planner supports adding, viewing, editing, deleting, and completing workouts.

This is a front-end demo, not production authentication. Account data is stored locally in the browser and is not shared or secured by a server.
